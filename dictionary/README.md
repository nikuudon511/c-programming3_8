# C++17 実技試験用辞書

オフラインで使える。**操作から探す**場合は `INDEX.md`、語句が分かる場合は検索を使う。最初に `std::vector` の項目を厚くした。例は短い断片なので、変数名と型を試験問題のヘッダーに合わせてから貼る。

## 30秒で探す

| 状況 | 方法 |
|---|---|
| 何をしたいかだけ分かる | `INDEX.md` の「目的別」から選ぶ |
| 関数名・語句が分かる | `python3 tools/search.py vector 削除` |
| 1件の説明全文を読む | `python3 tools/search.py --show V14` |
| Pythonが使えない | `rg -n 'push_back|削除' entries/`。`rg` がなければ `grep -Rni 'push_back' entries/` |

全てローカルファイル。リンクもネット接続不要。`catalog.tsv` は検索・表計算用の索引で、`INDEX.md` とともにスクリプトから再生成する。

必要な `#include` を探す場合は `HEADERS.md`。各分野のファイル冒頭にも主要ヘッダーを記している。

## 問題への当てはめ方

1. ヘッダーで型と状態の意味を確認する（`0` が空きか、座標は `row,col` かなど）。
2. 「候補を列挙」「値を1個消す」「隣接8マス」など、やりたい操作で引く。
3. コード例の型・境界・`const`・参照を問題に合わせる。
4. 1関数ずつビルドし、空・端・重複・範囲外の例を試す。

辞書に載っている断片がそのまま正解とは限らない。関数の仕様と、変更してよいファイルの範囲を優先する。

## 管理

各項目の原本は `entries/` のMarkdown。見出し `## V01` のID、次行の太字タイトル、`検索語:` を維持して追記する。索引更新と整合性チェック:

```bash
python3 tools/index.py
python3 tools/index.py --check
```

IDは変えない。検索語には日本語の操作名とC++の関数名を両方入れる。C++標準はこの辞書全体で **C++17** を前提にする。
