# 模擬問題07: マインスイーパーAI編

**目安: 45分。補完なし。** `solver.h` と `test.cpp` を読み、`solver.cpp` の `deduce()` だけを実装する。これは見えている数字から**確実に安全なマス**と**確実に地雷のマス**を探すAI。実際の地雷配置にはアクセスできない。

盤面は3×3で、各マスの整数は次の意味を持つ。

- `-2`: 未開封
- `-1`: 旗が付いたマス
- `0`〜`8`: 開封済みで、周囲8マスの地雷数を示す数字

各開封済みの数字マスについて、周囲の旗と未開封マスを数える。

1. `数字 == 旗の数` なら、周囲の未開封マスは全て安全。
2. `数字 == 旗の数 + 未開封マスの数` なら、周囲の未開封マスは全て地雷。

両方の結果を `Deduction` に入れて返す。同じ座標は各リストに1回だけ入れる。どちらとも確定できないマスは入れない。判定が矛盾する入力はテストしない。`neighbors()` と `addUnique()` は既に用意されている。

```bash
cmake -S . -B build
cmake --build build --target practice07
ctest --test-dir build --output-on-failure -R '^practice07$'
```
